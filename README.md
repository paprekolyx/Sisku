# SISKU · черновой макет интернет-магазина

> **v0.1.0-draft · 20.09.2026.** Макет для оценки дизайна и функций владельцем
> магазина. Название Sisku — временное, будет заменено. Не является боевым
> сайтом: юридические страницы, оплата и защита админки — следующих версий.

Мультибрендовый бутик премиальной одежды и парфюмерии: витрина с каталогом,
корзиной и формой заказа + админ-панель (заказы и статистика) без пароля,
доступ по ссылке.

**Сайт-черновик:** https://paprekolyx.github.io/Sisku/ *(адрес появится после публикации)*
**Админ-панель:** `…/admin.html`

## Из учебного проекта сохранены сильные решения

- Заказ создаётся **только серверной функцией** `create_order()`: цены и остатки
  берутся из базы, подменить сумму из браузера нельзя; всё в одной транзакции.
- Снапшоты цены, названия и размера в позициях заказа.
- Статусная модель Jira-workflow (`status_transitions`) + история статусов;
  смена статуса — только через `admin_set_status()` с проверкой переходов.
- Оплата — признак `is_paid` с датой, а не статус.
- Тексты сайта в `site_content` — правятся без кода (Table Editor).
- Корзина в localStorage, скелетоны, экранирование вывода, блокировка
  повторной отправки формы, honeypot от ботов, анти-спам 3 заказа / 10 минут.
- Маскирование контактов в админке + «глазик», выгрузка CSV (BOM, `;`).
- Идемпотентные нумерованные SQL-скрипты, версия на всех страницах.

## Осознанные упрощения черновика

- Админ-панель без пароля (доступ по ссылке): нет пользователей, ролей, сессий,
  журналов — заказы читаются анонимно (политика RLS `draft_anon_*`).
  В боевой версии — настоящая авторизация (см. отчёт по проекту, п. 1.7).
- Нет политики ПДн, оферты, отзывов, промокодов, галерей фото, уведомлений.
- Фото товаров — сгенерированные заглушки для оценки дизайна; реальные фото
  владелец предоставит в контент-пакете.
- База Supabase вне России: **только тестовые данные**, реальные ПДн не вводим.

## Как править

- Тексты сайта: Supabase → Table Editor → `site_content`.
- Товары: CSV в `data/` → импорт (порядок: brands, categories, products, variants).
- Ключи базы: только `assets/js/config.js`.
- Версия: константа `SITE_VERSION` там же; дублируется в футере и в шапке админки.
