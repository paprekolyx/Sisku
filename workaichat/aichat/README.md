## Правила каталога

- Обработанная версия — структурированная запись: карта постов (задание → результат →
  статус на дату обработки), реестр решений, задачи и их судьба, хвосты.
- Обработанные версии **не заменяют выгрузки-источники** ( originals — в `uploads/`);
  при расхождении приоритет у источника.
- Статусы пунктов сверяются с фактическим состоянием репозитория/базы на дату
  обработки (chat-1…3 — 07.10.2026, проект 0.16.0-draft; chat-4 —
  09.10.2026, проект 0.18.0-draft).
- Чат №4 (07–08.10.2026) являлся продолжением чата №3 и оборван на посте 7;
  текущая сессия (с 09.10.2026 — сверка пакета v0.17.1, волна v0.18.0
  «Карточка клиента», обработка чата №4, черновик v0.19.0) — продолжение
  чата №4; её выгрузка после завершения — источник для

- Каталог опубликован на GitHub в составе `workaichat/` (решение аналитика —
  чат №4, пост «Я 7» п.4, 08.10.2026): «просто молча лежит в гитхабе, ни в
