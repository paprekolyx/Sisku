## 2. Решения, принятые в чате №1 (действующие)

1. **Боевой стек:** только российские решения (152-ФЗ ч.5 ст.18) — Beget free,
   PHP 8 + MySQL 8; Supabase — только черновик, после переноса проект на pause.
2. **Черновик:** GitHub Pages + Supabase, мок-авторизация 123456, только тестовые
   данные, название Sisku — временное заглушечное.
3. **Оплата — признак `is_paid`, а не статус** (пост 7; статус «Оплачен» удалён
   из модели в v0.2.0, скрипт 06).
4. **Сохранены «сильные решения» учебного проекта:** серверный `create_order()`,
   снапшоты цен, статусная модель Jira-workflow + история, `site_content`,
   идемпотентные нумерованные SQL-скрипты, CSV-каталог, SemVer.
5. **Формат отчёта по волне — 4 пункта** (пост 17; редакция 06.10.2026 — только
   действия и изменения).
6. **Инструкции обновления — каждой волной** (`docs/update/update-v0XX.md`,
   пост 12.16 «инструкции всегда»).
7. **Политика цитирования:** задания в заметках — дословно по постам (итог поста 36).
