## 2. Решения и правила, принятые в чате №3 (действующие)

1. **`docs/viki-reestr.md` — постоянное имя** (версия внутри, обновление перезаписью,
   удаления не нужны); в REQUIRED check-repo — с v2.4.
2. **Формат отчётов — только действия и изменения** (заметки §6 п.2, ред. 06.10.2026):
   не менявшиеся документы/версии/скрипты не упоминаются; напоминания «не трогать»
   не пишутся; внутренние изменённые документы рабочей области — упоминаются.
3. **Структура рабочей области** (реестр §5.0, заметки §6 п.8): `sisku/` — зеркало
   GitHub (опубликованные документы только там, мастер = репо-копия);
   `new-shop-plan/` — только внутренние (реестр, заметки, план развития, `drafts/`,
   `archive/`); `~/ozhidaemye-deystviya.md` — трекер в корне; `reports/` — отчёты.
   Опубликованное из `new-shop-plan/` удаляется.
4. **Черновик волны — в `drafts/update-v0XX.md` до старта** (волна не начинается
   без утверждения состава аналитиком).
5. **Приёмка не переоткрывает волну** — реализованный fp сразу в «Уже реализовано»
   (заметки §6 п.10); задачи приёмки — в следующую волну.
6. **Изменяемые тексты не хардкодить** (заметки §6 п.11): fallback-тексты —
   нейтральные; названия служб — только из справочников/`site_content`.
7. **История ревизий — в конце документов** (заметки §6 п.9, записка Д1).
8. **Режим трекера 2.0:** только ожидаемые/планируемые пункты; архивация —
   только по явному запросу (копия vNN в `archive/`, заморозка).
9. **Вики «Текущие задачи» не синхронизируется** (страница — для аналитика).
10. **Ответы владельца (блок 6 закрыт):** сортировка — новинки + featured-пин;
    оферта — схема А (финал — ЮР-04); очереди служб доставки; ТЗ глобально утверждено.
