Условные обозначения циклов обновления:
- **[В]** — меняется в каждой волне (версионно-синхронный документ);
- **[Н]** — создаётся заново в каждой волне (старые не редактируются);
- **[С]** — событийный: меняется только при наступлении события (не каждая волна);
- **[З]** — замороженный/исторический: текст неизменяем (допускаются только
  помеченные служебные вставки, описаны явно).

Версия проекта на момент составления: **0.16.0-draft** (SITE_VERSION в
GitHub-копии config.js поднимается точечной правкой при загрузке пакета
волны v0.16.0; пакет волны подготовлен в клоне, ждёт загрузки; на GitHub
до загрузки остаётся 0.15.0-draft).
