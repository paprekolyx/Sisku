# Инструкция по обновлению черновика до v0.4.0-draft

**Куда смотреть:** этот файл — пошаговый порядок применения обновления v0.3.0 → v0.4.0.
Все упомянутые пути — относительно корня репозитория `Sisku`.
Правило проекта: **каждое обновление сопровождается такой инструкцией** (следующие
лежат рядом: `docs/update-v0XX.md`).

---

## Шаг 1. База данных (Supabase → SQL Editor)

Выполнить одним запросом файл **`supabase/07_draft_v040.sql`** (идемпотентен,
повторный запуск безопасен). Что делает: новый текст оплаты в `site_content`,
запрет менять признак оплаты у отменённых заказов (`admin_set_paid`), таблица
`admin_users` + стартовая запись-пример.

**Проверка после выполнения:** последний select вернёт
`payment_text_ok = true`, `users_count >= 1`.

## Шаг 2. Заменить существующие файлы в репозитории

| Файл | Что изменилось |
|---|---|
| `index.html` | hints формы заказа, оплата/доставка на всю ширину, валидация-разметка, типографика брендбука карточками |
| `admin.html` | вкладки-ссылки «Сборка»/«Пользователи», кнопка «Выйти», сортируемые заголовки таблицы, период «всё время», топ товаров таблицей, подключение mockauth/admintheme |
| `assets/css/styles.css` | hero без обрезки лица, подвал без подчеркиваний, скроллбары в стиле сайта, равные плашки палитры, карточки типографики |
| `assets/css/admin.css` | «На сайт» без подчеркивания и в цвет вкладок, стили сортировки/ролей/страницы входа/блокировок |
| `assets/js/site.js` | валидация телефона (+7/8 + 10 цифр) и почты (text@domen.ru, домены .рф) |
| `assets/js/admin.js` | сортировка, блокировка отменённых, «Сборка» раньше «Отменён», 4-я метрика времени и «кол-во», фикс-толщина столбцов, топ-таблица, hash #stats, выход |
| `README.md`, `SECURITY.md` | версии, новые страницы, примечания о мок-авторизации |

⚠️ **`assets/js/config.js` целиком НЕ перезаписывать!** В репозитории в нём стоят
реальные ключи базы, а в обновлении — заглушки. Отредактировать на GitHub одну строку:
`const SITE_VERSION = '0.3.0-draft';` → `'0.4.0-draft';`

## Шаг 4. Публикация и проверка

1. После push в `main` Pages обновится сам за 1–2 минуты (Deploy from a branch).
2. Открыть сайт и админку с **Ctrl + F5**.
3. Чек-лист приёмки:
   - `admin.html` без сессии редиректит на `login.html`; вход по паролю `123456`; «Выйти» возвращает на вход;
   - витрина: герой не обрезает голову; ссылки подвала без подчеркиваний; в форме заказа телефон `+7 (999) 123-45-67` проходит, `999 123-45-67` и `12345` — нет; почта `anna@example.ru` проходит, `anna@example` — нет;
   - брендбук: плашки палитры одной высоты, типографика двумя карточками, скролл тонкий;
   - «Условия заказа»: текст про три способа оплаты (СБП, карта, наличными);
   - админка: стрелки сортировки в №/Создан/Сумма работают asc/desc; у заказа в «Отменён» селект и кнопки оплаты заблокированы с подписью; у «Подтверждён» первый вариант перехода — «Сборка»;
   - статистика: период по умолчанию «Всё время»; 4 метрики времени с «кол-во»; топ товаров — таблица из 4 колонок; столбцы диаграмм одинаковой толщины;
   - новые страницы: «Сборка» показывает заказы в статусе «Сборка» обезличенно (создайте тестовый заказ и доведите до «Сборки», чтобы увидеть); «Пользователи» — создание/редактирование с ролями.

## Откат

- Код: revert коммита обновления в GitHub (Settings/commits → revert) или повторная

- База: изменения 07 обратимы вручную (текст оплаты вернуть update-ом, функцию
  `admin_set_paid` пересоздать из `03_functions.sql` старой редакции, таблицу
  `admin_users` можно оставить пустой или удалить `drop table`).
