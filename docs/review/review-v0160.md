#### Внешний ревью

Проведён полный обзор репозитория SISKU (17 страниц, ~6 тыс. строк JS, 25 SQL-скриптов, документация; check-repo.py запущен — проходит). 

Осознанные ограничения черновика (мок-пароль, anon-CRUD, читаемость заказов, enumeration track_order) принято не трогать. 

Предложены улучшения вне этих границ:

А. Безопасность: 

* A1 — iframe-предпросмотр товара (products.js srcdoc без sandbox) исполняет JS-путь brandvars.js из неконтролируемого localStorage-кэша токенов (real XSS/CSS-инъекция, не покрыта списком SECURITY.md); 
* A2 — отсутствие REVOKE EXECUTE на security definer-функциях (fix as explicit decision); 
* A3 — мок-гейт косметический, стоит уточнить в SECURITY.md; 
* A4 — CSV-импорт товаров без валидации brand_id/category_id.

Б. Производительность:
 
* 49 МБ изображений (~5 МБ/файл, hero без width/height/lazy) — пережать в WebP; 
* полная перезагрузка draft_admin_bundle после каждой смены статуса; 
* O(N²) itemsOf(); 
* пересоздание stubSrc dataURL на каждый рендер.

В. Надёжность данных: 

* анти-спам-окна и current_date в check_promo завязаны на UTC сервера (зафиксировать регламент); 
* used_count промокода не возвращается при отмене (задокументировать как решение); 
* нет лимитов длины текстовых полей в create_order (DoS/мусор в бандле и CSV).

**Комментарий**: должно быть долго локальное время, все UTC переводятся; использованные промокоды не возвращаются при отмене или возврате заказа - это решение, нужно задокументировать; лимит текстовых полей для создания в заказе - 1000 символов, добавить в план следующих волн. 

Г. Код: 

* локальные дубли money/phoneOk/emailOk поверх SiskuUtil в 5 модулях; 
* dbError мёртв после init (вечные скелетоны при сетевой ошибке); 
* смешение магических id/code статусов в SQL.

Д. Процессы: 

* нет GitHub Actions (check-repo + pglast — проверка SQL сейчас молча пропускается); 
* версии vendored-библиотек (supabase-js 2.116.0, chart.js 4.4.9) не отражены в README; 
* расширения check-repo (запрет inline onerror, контроль srcdoc/sandbox, сверка последней волны README↔update-.md); 
* нет .gitignore/.editorconfig, шум diffs в data/.csv.

**Комментарий**: отсутствие GitHub Actions намеренное.

Е. Мелочи: 

* safeUrl без encodeURI, 
* maskPhone раскрывает короткие номера, 
* внешний t.me URL захардкожен в index.html при наличии механизма site_content.

**Комментарий**: коротких номеров быть не должно, для этого в полях ввода стоит валидация по российскому формату номера. 

Дана таблица приоритетов: 

* 1) A1, 
* 2) WebP, 
* 3) CI, 
* 4) лимиты полей, 
* 5) точечные обновления состояния,
