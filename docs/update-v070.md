# Инструкция по обновлению черновика до v0.7.0-draft

**Куда смотреть:** этот файл — порядок применения обновления v0.6.0 → v0.7.0.
База данных не меняется (SQL-скрипты не добавляются).

---

## Шаг 1. Заменить файлы

| Файл | Что изменилось |
|---|---|
| `assets/js/ui.js` | новые компоненты: фирменный датапикер (`enhanceDates`) и степперы ± (`enhanceNumbers`) вместо нативных календаря и спиннеров |
| `assets/css/ui.css` | стили датапикера и степперов, скрытие нативных спиннеров |
| `shop.html` | заголовок колонки «Использовано / лимит» |
| `assets/js/shop.js` | колонка «Использовано N из M лимита», редактирование кликом по коду (код без жирного, кнопка «Изменить» убрана), датапикеры и степперы в модалке |
| `admin.html` | панель пагинации под таблицей заказов |
| `assets/js/admin.js` | пагинация по 30 заказов, локальный ключ даты в графике/CSV (убрал «лишний» день из-за UTC-сдвига), фикс-толщина столбцов воронки |
| `assets/css/admin.css` | стили пагинации |
| `index.html` | таблица размеров переехала в модальное окно (кнопка в «Условиях заказа»), кнопка отслеживания в контактах как «В корзину», убраны ссылка на репозиторий и «(черновик)» в подвале, плашки палитры без контрастов |
| `assets/css/styles.css` | фиксированный размер всех плашек палитры брендбука |
| `README.md`, `SECURITY.md`, `LICENSE.md` | версии и changelog |
| `tests/check-repo.py` | знает про update-v070 |

⚠️ `assets/js/config.js` — только строка `SITE_VERSION` → `'0.7.0-draft'`.

## Шаг 2. Добавить файлы

- `docs/update-v070.md` (этот файл).

## Шаг 3. Публикация и проверка

1. Push → Pages → **Ctrl + F5**.
2. Чек-лист:
   - «Магазин»: колонка «Использовано / лимит» читается как «Использовано 2 из 100 лимита»; клик по коду промокода открывает редактирование; в модалке даты открывают фирменный календарь (месяц листается, «Сегодня»/«Очистить» работают), у числовых полей свои ± вместо стрелок браузера;
   - админка: при >30 заказах под таблицей пагинация «Стр. X из Y», кнопки Ранее/Далее, сброс страницы при фильтрах и сортировке;
   - график «Заявки и суммы по дням»: только реальные даты заказов (без «фантомного» дня), старые слева;
   - воронка статусов: столбцы тонкие, как в «Доставка и оплата»;
   - витрина: в «Условиях заказа» кнопка «Таблица размеров» открывает модалку с таблицей; в контактах кнопка отслеживания выглядит как акцентная кнопка; в подвале нет ссылки на репозиторий и слова «(черновик)»;
   - брендбук: все плашки палитры обеих тем одинакового размера.
3. Локально: `python3 tests/check-repo.py`.

## Откат

Revert коммита; изменений базы нет.
