# Инструкция по обновлению черновика до v0.7.0-draft

**Куда смотреть:** этот файл — порядок применения обновления v0.6.0 → v0.7.0.
База данных не меняется (SQL-скрипты не добавляются).
Формат инструкций с v0.7.0: файлы сгруппированы по папкам источника,
новый файл или обновляемый — не важно.

---

## 1. Файлы для загрузки (по папкам, откуда брать)

- **Корень репозитория:** `index.html`, `admin.html`, `shop.html`, `README.md`, `SECURITY.md`, `LICENSE.md`
- **assets/js/:** `ui.js`, `admin.js`, `shop.js`
- **assets/css/:** `ui.css`, `admin.css`, `styles.css`
- **docs/:** `update-v070.md`
- **tests/:** `check-repo.py`

## 2. Версия

В `assets/js/config.js` поменять только строку
`const SITE_VERSION = '0.6.0-draft';` → `'0.7.0-draft';`
Ключи базы в этом файле не трогать.

## 3. Публикация и проверка

1. Push в `main` → Pages обновится сам за 1–2 минуты → **Ctrl + F5** на витрине и в админке.
2. Чек-лист:
   - «Магазин»: колонка «Использовано / лимит» читается как «Использовано 2 из 100 лимита»; клик по коду промокода открывает редактирование; в модалке даты открывают фирменный календарь (месяц листается, «Сегодня»/«Очистить» работают), у числовых полей свои ± вместо стрелок браузера;
   - админка: при >30 заказах под таблицей пагинация «Стр. X из Y», кнопки Ранее/Далее, сброс страницы при фильтрах и сортировке;
   - график «Заявки и суммы по дням»: только реальные даты заказов (без «фантомного» дня), старые слева;
   - воронка статусов: столбцы тонкие, как в «Доставка и оплата»;
   - витрина: в «Условиях заказа» кнопка «Таблица размеров» открывает модалку с таблицей; в контактах кнопка отслеживания выглядит как акцентная; в подвале нет ссылки на репозиторий и слова «(черновик)»;
   - брендбук: все плашки палитры обеих тем одинакового размера.

## 4. Финальная проверка

Локально перед коммитом: `python3 tests/check-repo.py` (выход 0 = всё зелёное).
Актуальный архив со всеми файлами: `sisku-draft.zip`.

## Приложение: что изменилось в каждом файле

| Файл | Изменение |
|---|---|
| `assets/js/ui.js` | компоненты `enhanceDates` (фирменный календарь) и `enhanceNumbers` (степперы ±) |
| `assets/css/ui.css` | стили календаря и степперов, скрытие нативных спиннеров |
| `shop.html` | заголовок колонки «Использовано / лимит» |
| `assets/js/shop.js` | «Использовано N из M лимита», правка кликом по коду (без жирного, без кнопки «Изменить»), календари и степперы в модалке |
| `admin.html` | панель пагинации под таблицей заказов |
| `assets/js/admin.js` | пагинация по 30, локальный ключ даты в графике и CSV (убран фантомный день из-за UTC), фикс-толщина воронки |
| `assets/css/admin.css` | стили пагинации |
| `index.html` | таблица размеров в модалке + кнопка в «Условиях заказа», акцентная кнопка отслеживания, чистый подвал, плашки палитры без контрастов |
| `assets/css/styles.css` | фиксированный размер плашек палитры |
| `README.md`, `SECURITY.md`, `LICENSE.md` | версии и changelog |
| `tests/check-repo.py` | знает про `docs/update-v070.md` |

## Откат

Revert коммита; изменений базы нет.
