# Инструкция по обновлению черновика до v0.5.0-draft

**Куда смотреть:** этот файл — порядок применения обновления v0.4.0 → v0.5.0.
Пути — от корня репозитория `Sisku`.

---

## Шаг 1. База данных (Supabase → SQL Editor)

Выполнить одним запросом **`supabase/09_admin_bundles.sql`** (идемпотентен).
Создаёт функции `draft_admin_bundle()` и `draft_assembly_bundle()` (админка и
«Сборка» грузятся одним запросом вместо 4–7) и политику DELETE для `admin_users`.

**Проверка:** финальный select вернёт `statuses_in_bundle ≥ 1`, `stock_rows ≥ 1`.

## Шаг 2. Заменить файлы

| Файл | Что изменилось |
|---|---|
| `assets/js/admin.js` | загрузка одним запросом-сборкой |
| `assets/js/assembly.js` | один запрос; кнопка «→ Отправлен»; сигнализация остатка < 3 |
| `assets/js/users.js` | редактирование кликом по ФИО, удаление, защита от двойного «Сохранить» |
| `assets/js/site.js` | hero-картинка переключается по теме |
| `assets/js/config.js` | только строка `SITE_VERSION` → `'0.5.0-draft'` (ключи не трогать!) |
| `assembly.html` | колонка «Действия», плашка предупреждения |
| `users.html` | id у кнопки «Сохранить» |
| `assets/css/admin.css` | вкладки без подчеркиваний, стили остатка < 3 и кликабельного ФИО |
| `README.md`, `SECURITY.md`, `LICENSE.md` | версии и строки changelog |

## Шаг 3. Добавить файлы

- `assets/img/hero-dark.jpg` — герой тёмной темы (мужской образ);
- `supabase/09_admin_bundles.sql`;
- `docs/update-v050.md` (этот файл);
- `tests/check-repo.py` — обновлённая версия (знает про 09 и hero-dark).

## Шаг 4. Публикация и проверка

1. Push → Pages за 1–2 минуты → **Ctrl + F5**.
2. Чек-лист:
   - переключатель темы на витрине меняет героя: светлая — женский образ, тёмная — мужской;
   - вкладки админки (Заказы / Статистика / Сборка / Пользователи) без подчеркиваний на всех страницах;
   - Network в DevTools: админка делает **один** fetch `rpc/draft_admin_bundle` вместо семи запросов; статистика открывается без дополнительных запросов;
   - «Сборка»: кнопка «→ Отправлен» переводит заказ (он исчезает из списка после обновления); остаток «2 ⚠» подсвечен, сверху плашка «остаток менее 3 шт»;
   - «Пользователи»: клик по ФИО открывает редактирование (ФИО без жирного), кнопка «Удалить» спрашивает подтверждение и удаляет; быстрые повторные клики по «Сохранить» больше не создают дубли (кнопка блокируется на время запроса);
   - дубли, созданные ранее кликами, можно удалить новой кнопкой.
3. Локально перед коммитом: `python3 tests/check-repo.py`.

## Почему раньше грузилось долго (для понимания)

Семь параллельных запросов к Supabase упирались в очередь соединений пула
бесплатного тарифа: часть запросов висела в pending, пока другие не завершатся,
плюс холодный старт проекта после простоя. Один запрос-сборка убирает очередь;
радикальное лечение (свой сервер в РФ) — в боевой версии, волна M1.

## Откат

Revert коммита; функции из 09 можно удалить (`drop function draft_admin_bundle(),
draft_assembly_bundle();`) — старый код админки к ним не обращается после отката
файлов из шага 2.
