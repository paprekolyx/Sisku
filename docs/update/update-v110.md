# Инструкция по обновлению черновика до v0.11.0-draft

**Куда смотреть:** этот файл — порядок применения обновления v0.10.0 → v0.11.0.
Формат: файлы сгруппированы по папкам источника, новый файл или обновляемый — не важно.

---

## 1. Файлы для загрузки (по папкам, откуда брать)

- **Корень репозитория:** `index.html`, `admin.html`, `products.html`, `users.html`, `clients.html`, `brandbook.html`, `manage.html`, `sitecontent.html`, `sitemap.html`, `README.md`, `SECURITY.md`, `LICENSE.md`
- **assets/js/:** `site.js`, `admin.js`, `products.js`, `looks.js`, `brandvars.js`, `brandbook.js`, `clients.js`
- **assets/css/:** `styles.css`, `admin.css`
- **supabase/:** `14_brandbook.sql`
- **docs/:** `update-v110.md`, `feature-proposals.md`
- **tests/:** `check-repo.py`

## 2. Версия

В `assets/js/config.js` поменять только строку
`const SITE_VERSION = '0.10.0-draft';` → `'0.11.0-draft';`. Ключи базы не трогать.

## 3. База, публикация и проверка

1. Supabase → SQL Editor → выполнить **`supabase/14_brandbook.sql`**:
   таблицы `brand_colors` (токены витрины, отдельно от site_content) и
   `brand_templates` (шаблоны палитр), `create_order()` v4 (скидка комплекта
   по фактическому составу корзины). Самопроверка: `color_rows = 20`,
   `brand_policies = 8`.
2. Push в `main` → Pages за 1–2 минуты → **Ctrl + F5**.
3. Чек-лист:
   - **«Управление → Брендбук»:** плашки обеих тем с пипеткой и hex-полем (интерфейс как в брендбуке), типографика (базовый px, масштаб заголовков), живые контрасты WCAG с бейджами AA/«ниже нормы», кнопка «Предпросмотр» (модалка с карточкой товара, кнопками, текстом и полем в обеих темах), кнопка «Брендбук (справка)» открывает окно, идентичное витринному; шаблоны: сохранить текущие цвета с названием и комментарием, применить, удалить; после «Сохранить цвета» витрина меняет палитру после Ctrl + F5; в тулбаре — замер скорости применения темы;
   - **витрина, «Готовые образы»:** карточка лука теперь с описанием и таблицей состава (название + цена, как в админке), старой зачёркнутой ценой и новой; для позиций «вся размерная сетка» в карточке появился выбор размера; если части товаров нет в наличии — подтверждение «добавить доступные со скидкой / отказаться»; тост больше не показывает undefined;
   - **статистика:** топ товаров сортируется кликом по «Кол-во»/«Сумма»; у воронки статусов переключатель «Диаграмма / Таблица»;
   - **заказы:** после смены статуса в карточке выбранный фильтр статуса не сбрасывается и подпись в селекте соответствует значению;
   - **товары:** в карточке товара кнопка «Выбрать фото» вместо системного поля, имя файла и пометка о сжатии видны рядом;
   - **комплекты (админка):** в редакторе крестик удаления позиции стал заметным; вариант «— вся размерная сетка —» сохраняется как пустой;
   - **«Пользователи → Клиенты»:** новая страница-мок: таблица (ФИО, телефон, e-mail, первый/последний заказ, сумма, количество), клик по ФИО открывает карточку с редактированием и комментарием.

## 4. Финальная проверка

Локально перед коммитом: `python3 tests/check-repo.py` (выход 0).
Зеркало просмотра: `cd /home/user && cp sisku-draft/*.html sisku-draft/README.md sisku-draft/LICENSE.md sisku-draft/SECURITY.md sisku-pages/`.
Актуальный архив: `sisku-draft.zip`.

## Откат

Revert коммита; таблицы `brand_colors`/`brand_templates` можно оставить пустыми
или удалить — витрина без них работает на дефолтных токенах CSS.
