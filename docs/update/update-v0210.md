## Приложение Б. Формы таблиц и RPC (фактические)

    badges: id · code (unique: new/hit/ending/soon/percent) · name
      (New/Хит/Заканчивается/Скоро/%) · is_system (true у New) · is_active ·
      sort_order (New 1 … % 5) · created_at
    product_badges: id · product_id (FK products, cascade) · badge_id
      (FK badges) · sort_order · created_at · unique(product_id, badge_id)
      · индексы product_id / badge_id

    draft_save_product_badges(p jsonb) : p = { product_id: int|text,
      badge_ids: [int] (пусто = снять все) } → { ok: true, count: int }
      | raise: «Товар не найден: id N» / «Бейдж не найден или неактивен:
        id N» / «badge_ids — не массив» / «ID бейджа — не число» /
        «product_id не указан или не число» / «Параметр p — не объект»

    draft_storefront_bundle() v3 → v2-состав (11 ключей)
      + badges: [ {id, code, name, is_system, is_active, sort_order,
                   created_at} … активные, order by sort_order, id ]
      + product_badges: [ {id, product_id, badge_id, sort_order,
                           created_at} … только активных бейджей,
                           order by sort_order, id ]
