## 1. Что изменилось (состав волны)

### 1.0. Решения до старта волны (утверждены аналитиком 09.10.2026)

**Д1** — пороги сегментов: ключи `site_content` `segments.*`, без новой
таблицы (аналитик: «не имеет значения — владелец при проверке функционала
установит корректные значения, а аналитик сделает бэкап»; дефолты: VIP —
заказов ≥ 5 **или** сумма ≥ 100000 ₽, «уснул» — 90 дней). **Д2** — сегменты
считает сервер (`draft_clients_bundle` v3, один запрос — грабля №6);
**кросс-фильтры подтверждены**: «уснувший VIP» виден и в VIP, и в «уснули»
(`is_dormant` — независимый признак). **Д3** — «динамика повторных продаж по
месяцам» и «средний промежуток между покупками» (из заглушки v0.13.0) —
**перенесены в fp №8b** (исполнено: карта №8 дополнена). **Д4** — настройка
порогов **обязательно на той же вкладке, в модальном окне с кнопкой
сохранения** (исполнено: кнопка «Пороги» → модалка). **Д5** — контакты:
маска + «глазик»; после раскрытия tel:/mailto: только для валидных
(паттерн users.js). **Д6** — пилюли сегментов: 4 правила `admin.css`
(приём v0.15.0 — color-mix, WCAG AA). **Д7** — без селектора периода в
подвкладке; **создан новый fp №26** «Селектор периода для всех подвкладок
«Статистики»» — приоритет заморожен, не реализовывать до отдельного указания
и пересмотра приоритетов fp (исполнено: карта №26). **Д8** — check-repo
v2.8. **Д9** — CSV-экспорт сегмента с полными контактами (паттерн clients
v0.13.0; данные тестовые). **Д10** — пакет минимального состава (HTML чистые
с v0.18.0 — только фактически изменённые файлы); список — от корня с
углублением в папки (грабля №18).

### 1.1. База — скрипт 30, `draft_clients_bundle` v3

- **`supabase/30_client_segments.sql` (НОВЫЙ):**
  - посев 3 ключей `site_content` — `segments.vip_orders_min` ('5'),
    `segments.vip_sum_min` ('100000'), `segments.dormant_days` ('90') —
    **только отсутствующие** (on conflict do nothing — культура F21;
    повторный прогон — no-op);

    агрегация fix 42803 сохранена): строки `stats` + `segment`

    сумма ≥ порога; приоритет VIP > repeat > new) + `is_dormant`
    (последний заказ старше `dormant_days`; клиент без заказов —
    false); корень + `thresholds` (эхо порогов для UI); **безопасный CAST**

    fallback на дефолты — бандл не падает; регэксп-якоря с долларами не
    используются — правило 4 регламента); форма v2 сохранена —
    `clients.html`/`clients.js` v0.18.0 не затронуты (Д2/Д8 черновика).
