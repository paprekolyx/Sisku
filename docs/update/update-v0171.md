## 7. Урок для регламента

**Грабля №17 — артефакты загрузки через GitHub Web UI:** (а) файлы с точкой
в начале имени не отображаются в рабочей области ИИ-чата и не передаются
пакетом — создаются вручную (Add file → Create new file); (б) бинарные файлы
при такой загрузке могут оказаться пустыми заглушками (в этой волне — `.jpg`
по 2 байта вместо ≈5 МБ); (в) текстовые файлы могут получить ведущую пустую
строку CRLF (в этой волне — 3 HTML). **Правило: после каждой загрузки —
контроль свежего клона**: check-repo, размеры/первые байты бинарных файлов,
diff с рабочей копией (исполнено 08.10.2026 — все три отклонения найдены именно
так).
