## Приложение Б. Формы таблиц и RPC (фактические — для сверки и будущей приёмки)

**category_attrs:** id serial PK; category_id int NOT NULL → categories(id)
ON DELETE CASCADE; code text NOT NULL; name text NOT NULL; type text NOT
NULL CHECK (type IN ('text','number','enum')); enum_values jsonb NOT NULL
DEFAULT '[]'; sort_order int NOT NULL DEFAULT 1; show_in_list bool NOT NULL
DEFAULT false; is_filterable bool NOT NULL DEFAULT false; is_active bool NOT
NULL DEFAULT true; created_at timestamptz NOT NULL DEFAULT now();
UNIQUE(category_id, code). Индекс category_attrs_category_idx.

**product_attrs:** id serial PK; product_id int NOT NULL → products(id) ON
DELETE CASCADE; attr_id int NOT NULL → category_attrs(id) ON DELETE CASCADE;
value text NOT NULL DEFAULT ''; created_at timestamptz NOT NULL DEFAULT
now(); UNIQUE(product_id, attr_id). Индексы product_attrs_product_idx,
product_attrs_attr_idx.

**RLS:** anon_read_category_attrs, anon_read_product_attrs (select, to anon,
authenticated, using (true)); write-политик нет — запись только RPC.

**RPC (все SECURITY DEFINER, search_path public):**
- `admin_save_category_attr(p_attr jsonb) → jsonb {ok, id}`; p_attr =
  {id?, category_id, code, name, type, enum_values[], sort_order,
  show_in_list, is_filterable, is_active};
- `admin_delete_category_attr(p_attr_id integer) → jsonb {ok,
  deleted_values}`;
- `draft_save_product_attrs(p_product_id integer, p_attrs jsonb) → jsonb
  {ok, saved, deleted}`; p_attrs = {"<attr_id>": "<value>"}; пустое/пробельное
  значение — удаление строки;
- `draft_attrs_bundle() → jsonb {attrs: [{id, category_id, code, name, type,
  enum_values, sort_order, show_in_list, is_filterable, is_active}], values:
  [{product_id, attr_id, value}]}` (attrs — только активные).

**draft_storefront_bundle v4:** ключи v3 (brands, categories, products,
variants, content, payments, deliveries, looks, look_items, brand,
return_reasons, badges, product_badges) + `attr_dict` [{id, category_id,
code, name, type, enum_values, is_filterable, show_in_list, sort_order}];
строки products — все колонки + `attrs` {attr_id: value} (только заполненные
значения активных атрибутов категории товара).

**draft_clients_bundle v4:** clients (без изменений), stats — строки
{client_id, orders, sum, paid_sum, first_order, last_order, segment,
**is_new, is_repeat, is_vip**, is_dormant}, thresholds {vip_orders_min,
vip_sum_min, dormant_days}.
