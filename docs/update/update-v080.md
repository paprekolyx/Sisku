# Инструкция по обновлению черновика до v0.8.0-draft

**Куда смотреть:** этот файл — порядок применения обновления v0.7.0 → v0.8.0.

---

## 1. Файлы для загрузки (по папкам, откуда брать)

- **Корень репозитория:** `shop.html`, `products.html`, `README.md`, `SECURITY.md`, `LICENSE.md`
- **assets/js/:** `shop.js`, `products.js`
- **assets/css/:** `admin.css`
- **supabase/:** `11_product_management.sql`
- **docs/:** `update-v080.md`
- **tests/:** `check-repo.py`

## 2. Версия

В `assets/js/config.js` поменять только строку
`const SITE_VERSION = '0.7.0-draft';` → `'0.8.0-draft';`
Ключи базы в этом файле не трогать.

## 3. База, публикация и проверка

1. Supabase → SQL Editor → выполнить **`supabase/11_product_management.sql`**
   (открывает черновую запись каталога для админки; самопроверка вернёт `write_policies = 8`).
2. Push в `main` → Pages за 1–2 минуты → **Ctrl + F5**.
3. Чек-лист:
   - «Магазин»: сверху переключатель «Промокоды и категории» / «Товары»; на странице магазина под промокодами — таблица категорий (создание, правка кликом по названию, авто-slug из названия, удаление с защитой FK, счётчик товаров);
   - «Товары»: список с фото-миниатюрой, артикулом, ценой, суммарным остатком (красным при < 3), кнопкой «активен/скрыт» и кнопкой «Карточка»;
   - «Новый товар»: форма с валидацией (артикул, название, цена, категория), редактор вариантов (размер/объём + остаток, добавление/удаление строк), черновая загрузка фото (файл сжимается в браузере и виден в предпросмотре; можно указать путь/ссылку вместо файла) и **живой предпросмотр карточки витрины** справа;
   - редактирование: клик по названию в списке или кнопка «Карточка» — форма предзаполнена, включая варианты;
   - CSV: «Шаблон CSV» скачивает файл-пример; «Загрузить CSV» принимает файл в формате `data/products.csv` (колонки article,name,price,brand_id,category_id,description,image_url,is_active), показывает отчёт «импортировано N / пропущено строк с ошибками»;
   - витрина: созданный/активированный товар появляется в каталоге, скрытый — исчезает.

## 4. Финальная проверка

Локально перед коммитом: `python3 tests/check-repo.py` (выход 0 = зелёный).
Актуальный архив: `sisku-draft.zip`.

## Приложение: что где появилось

| Файл | Изменение |
|---|---|
| `supabase/11_product_management.sql` | anon-политики insert/update/delete для products, categories, product_variants (черновое допущение, задокументировано в SECURITY) |
| `shop.html`, `assets/js/shop.js` | переключатель разделов, секция категорий с CRUD и авто-slug |
| `products.html`, `assets/js/products.js` | новая страница: список товаров, активация, карточка с предпросмотром и вариантами, сжатие фото, CSV-импорт и шаблон |
| `assets/css/admin.css` | миниатюры, сетка формы, липкий предпросмотр, редактор вариантов |

## Откат

Revert коммита; политики из скрипта 11 при желании снимаются
`drop policy … on public.products/categories/product_variants` —
витрина продолжит работать (чтение не затрагивалось).
