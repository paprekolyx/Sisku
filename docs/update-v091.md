# Инструкция по обновлению черновика до v0.9.1-draft

**Куда смотреть:** этот файл — порядок применения обновления v0.9.0 → v0.9.1 (patch-волна:
регрессия промокодов + визуальные правки). База данных не меняется.

## 1. Файлы для загрузки (по папкам, откуда брать)

- **Корень репозитория:** `shop.html`, `manage.html`, `sitemap.html`, `README.md`, `SECURITY.md`, `LICENSE.md`
- **assets/js/:** `shop.js` (не менялся логически, проверен), `manage.js`, `site.js`
- **assets/css/:** `ui.css`, `admin.css`
- **docs/:** `update-v091.md`
- **tests/:** `check-repo.py`

## 2. Версия

В `assets/js/config.js` поменять только строку
`const SITE_VERSION = '0.9.0-draft';` → `'0.9.1-draft';`. Ключи базы не трогать.

## 3. Публикация и проверка

1. Push в `main` → Pages за 1–2 минуты → **Ctrl + F5**.
2. Чек-лист:
   - **«Магазин → Промокоды» работает без «Обновить»:** список грузится сразу, клик по строке кода открывает карточку, «Новый промокод» создаёт запись (регрессия v0.9.0: при вырезке категорий удалилась модалка промокода, теперь возвращена);
   - карта сайта: нет группы «Внешние системы» и узла «Админ-панель» в витрине; разделы витрины — отдельными плашками; у всех узлов групп «Заказы и производство», «Магазин», «Управление» есть описания;
   - степперы ± в модалках (промокод, способы) не слипаются: плюс сверху, минус снизу, с зазором;
   - скроллбары кастомных селектов, модалок и таблиц в админке — тонкие, в цвет линий (не системные);
   - пилюля статуса в карточке заказа читается в обеих темах (тёмный текст на бронзе в светлой, тёмный на шампани в тёмной);
   - корзина: попытка добавить больше остатка даёт понятное сообщение («На складе 1 шт. этого размера — в корзине уже 1, добавить больше нельзя»);
   - «Управление → Оплата и доставка»: на строках кнопка «Удалить» (с подтверждением; способ из заказов база не отдаст), правка — кликом по названию; в баннере напоминание обновить тексты order.payment.text / order.delivery.text на странице «Сайт»;
   - новый активный способ оплаты/доставки сразу появляется в выпадающих списках формы заказа на витрине (проверить созданием тестового способа).

## 4. Финальная проверка

Локально перед коммитом: `python3 tests/check-repo.py` (выход 0).
Актуальный архив: `sisku-draft.zip`.

## Откат

Revert коммита; база не затрагивалась.
