# Инструкция по обновлению черновика до v0.10.0-draft

**Куда смотреть:** этот файл — порядок применения обновления v0.9.1 → v0.10.0.
Формат: файлы сгруппированы по папкам источника, новый файл или обновляемый — не важно.

---

## 1. Файлы для загрузки (по папкам, откуда брать)

- **Корень репозитория:** `index.html`, `shop.html`, `categories.html`, `brands.html`, `products.html`, `looks.html`, `assembly.html`, `README.md`, `SECURITY.md`, `LICENSE.md`
- **assets/js/:** `shop.js`, `products.js`, `site.js`, `looks.js`
- **assets/css/:** `styles.css`
- **supabase/:** `13_reserve_and_looks.sql`
- **docs/:** `update-v100.md`, `feature-proposals.md`
- **tests/:** `check-repo.py`

## 2. Версия

В `assets/js/config.js` поменять только строку
`const SITE_VERSION = '0.9.1-draft';` → `'0.10.0-draft';`. Ключи базы не трогать.

## 3. База, публикация и проверка

1. Supabase → SQL Editor → выполнить **`supabase/13_reserve_and_looks.sql`**:
   таблицы `looks`/`look_items`, колонка `orders.look_id`, функция резервов
   `draft_reserved_map()`, `admin_set_status()` v2 (возврат остатков при отмене
   и возврате), `create_order()` v3 (скидка комплекта). Самопроверка:
   `look_policies = 8`, `look_column_ok = look_id`.
2. Push в `main` → Pages за 1–2 минуты → **Ctrl + F5**.
3. Чек-лист:
   - **«Магазин → Промокоды»:** клик по коду открывает карточку на редактирование (регрессия v0.9.1 устранена), создание и тумблер работают;
   - **«Магазин → Комплекты»:** создание лука (название, описание, скидка %, состав из товаров с вариантами), правка кликом по названию, тумблер, удаление;
   - **витрина:** раздел «Готовые образы» между каталогом и условиями; карточка лука с ценой «вместо / со скидкой»; «В корзину целиком» добавляет все позиции и применяет скидку комплекта в сводке заказа; убранная из корзины позиция комплекта снимает скидку с тостом;
   - **резервирование:** в «Товарах» колонка «В резерве» показывает единицы в открытых заказах; отмените тестовый заказ — остаток на складе вернётся (сравните «Остаток» до и после);
   - **«Сборка»:** баннер объясняет резервирование и автовозврат остатков;
   - подсказка на «Оплата и доставка» напоминает про тексты site_content.

## 4. Финальная проверка

Локально перед коммитом: `python3 tests/check-repo.py` (выход 0).
Актуальный архив: `sisku-draft.zip`.
Зеркало страниц для просмотра в рабочей области: папка `sisku-pages/`
(обновляется командой из её заметки `_ZERKALO.md`).

## Откат

Revert коммита; функции из скрипта 13 при необходимости заменяются предыдущими
редакциями (09/10), таблицы `looks`/`look_items` можно оставить пустыми.
